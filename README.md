# Introdução a Machine Learning

[![Abrir no Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/samuelfsd/intro-ml/blob/main/notebooks/01_introducao_ml.ipynb)

Material de introdução a Machine Learning com scikit-learn: os conceitos fundamentais (carregar e tratar dados,
treino/teste, treinar e aplicar um modelo) usando um dataset de salários
([Hugging Face](https://huggingface.co/datasets/maxfactor71/Employee_Performance_Salary)).

## Como rodar

Pelo botão do Colab acima, ou localmente com [uv](https://docs.astral.sh/uv/):

```bash
uv sync
uv run jupyter lab notebooks/01_introducao_ml.ipynb
```
